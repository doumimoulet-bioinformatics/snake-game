 # snake game :
my first python project!
## About:
this is a classic snake game developed using python.
the player controls a snake using the keyboard arrow keys. the goal is to eat the food, grow longer and avoid hitting the walls or the snake's own body.
this project was created as a part of my journey to learn python programming and practice real world projects.
 ## Technologies and Libraries:
_python __ programming language.
_curses __used to create the terminal-based game interface and handle keyboard input 
_random__ used to generate random food positions.
## Installation and usage:
1_ INSTALL PYTHON: make sure python is installed on your computer.
2_ INSTALL THE REQUIRED LIBRARAY: on windows, open your terminal and run:
pip install windows-curses
3_ RUN THE GAME:
navigate to project folder and run:
python snake_game.py
